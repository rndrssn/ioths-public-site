### New

- OneDrive storage (Full Unlock): sync your Library to a dedicated app folder in your personal Microsoft account, with restore and explicit keep-local / replace-local choices. Portable export works from a OneDrive Library too.
- Search supports exact quoted phrases and tag-based filtering.
- Search results show matching context from inside a note when the title does not match.
- The editor suggests existing tags while typing `#`.
- Tasks can be grouped by note or tag, with groups that can be collapsed.
- Kanban can use landscape orientation on iPhone and returns to portrait when leaving Kanban.
- Full-screen images zoom around the pinch location rather than always from the center.
- Kanban can switch between note cards and tasks grouped under their source note.

### Improved

- Tiles are now the default main view; the previous Thoughts view has been removed.
- Search terms are highlighted consistently across list, tile, and Kanban views.
- Compact list and tile layouts are easier to scan, with less visual clutter and more focused metadata.
- Notes without tasks no longer display a misleading progress marker.
- Task lists show note links once in each note header instead of repeating them beside every task.
- Pinned notes now separate the remaining collection under “Other notes,” and the Pinned header reads the same in list and tile views.
- Storage, sync, import, and vault-change operations remain visibly in progress until they complete, preventing accidental dismissal or duplicate actions.
- Vault-selection failures stay on screen and show an error instead of silently closing the sheet.
- Starting work at the WIP limit now opens the limit setting instead of moving another note back to Open.

### Fixed

- Files-folder storage now makes clear that the selected Files provider must allow folder selection.
- The search Filter button now responds reliably on iOS 26, including before any text is entered.
- Emptying a large Trash is faster and now shows deletion progress instead of appearing unresponsive.
- Typing in task-heavy notes avoids an immediate duplicate full-document Markdown styling pass, reducing typing lag.
- Searches containing text that cannot form a searchable token no longer fall back to showing the entire vault.
- Leaving Kanban in landscape no longer leaves the app in an unsupported orientation.
- Long-pressing a pinned note in List view now highlights only that note.
- Tags in newly created notes — including the welcome notes and notes made from shared text, images, or audio — now appear in the tag list and filters.
