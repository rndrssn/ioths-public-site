Search, tasks, and everyday note browsing are smoother in this update.

- Search now supports exact quoted phrases and tag-based filtering.
- Search results show matching context from inside a note when the title does not match.
- Search terms are highlighted consistently across List, Tile, and Kanban views.
- The editor suggests existing tags while you type `#`.
- Tasks can be grouped by note or tag, with groups that can be collapsed.
- Task note links are shown once in each group header instead of repeating beside every task.
- Kanban works in landscape on iPhone and returns to portrait when you leave it.
- Full-screen images zoom around the pinch location.
- Tile is now the default main view; the former Thoughts view has been removed.
- Compact List and Tile layouts are easier to scan, with clearer task progress and less visual clutter.
- Notes without tasks no longer show a misleading progress marker.
- Pinned notes now appear separately from the rest of the collection under “Other notes.”
- Storage, sync, import, and storage-change operations remain visibly in progress until they finish, helping prevent accidental dismissal or duplicate actions.
- Storage-selection failures remain visible and now show a clear error.
- Emptying a large Trash now shows deletion progress instead of appearing unresponsive.
- Task-heavy notes avoid unnecessary Markdown styling work while typing, reducing editor lag.
- Searches containing text that cannot form a searchable token no longer show the entire collection.
