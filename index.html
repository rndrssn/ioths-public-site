Offline notes in Markdown

A note doesn’t
need a plan.

You can know that something is worth writing down without knowing what to do with it. ioths is a notes app for iPhone and iPad. It works offline and saves Markdown files, so the note can become part of an existing Obsidian library.

01 / Observations

Where a notes app can help.

What gets in the way.

Away from the desk

Waiting until later.

A question comes up on the train. Waiting until you’re back at your desk means relying on memory, including the bit that made the question worth asking.

In ioths, you can write the note on your phone without a connection. Sync is optional.

Before the task

Deciding too soon.

An observation may become a task, but it may also be wrong. Giving it a project and a status doesn’t make it any better understood.

Start with text. If there is a next step, add a checkbox to that note.

Keeping the files

Depending on a format.

The notes may outlast the tool used to write them. A file you can read elsewhere leaves you more room to change how you work.

ioths writes .md files with YAML frontmatter. Obsidian and ordinary text editors can read them.

02 / In practice

An example note, with its follow-up work.

Keep the task with its context.

The example below starts with a question about a changed deadline. The next steps appear in the same note, beside the reason for doing them.

# Why are we reviewing this again?

There is something to check.

A checklist makes the follow-up explicit. Its open items also appear in Tasks, alongside items from other notes. The original question stays where it was written.

- [x] Compare scope with the deadline

#delivery

One item done; one still open.

Mark the note in progress to put it in the board’s In Progress lane. The work-in-progress limit caps how many notes carry that status. You choose the limit.

03 / Emergence

Conway’s Game of Life.

What the icon refers to.

Conway’s Game of Life applies a fixed rule to every cell on a grid. Each update depends on the cell and its eight neighbours. The same starting cells produce the same sequence every time, although the larger pattern can be difficult to anticipate from those rules alone.

This is the emergence reference in the icon. There is a related idea in how ioths handles a note: you can write a question, return with more context, and find work that wasn’t apparent when you started. The useful structure develops through those actions.

The connection is an analogy. Game of Life does not model how people think.

04 / Working conditions

The practical part.

The rest of the tool stays close to the file.

Capture and find.

Type, dictate, take a photo, or use the Share Extension. Tags, pinned notes, search, archive, and trash recovery keep the library usable. PDF conversion is reviewed on-device before you save.

See the work.

The Tasks view collects open checklist items from across the library. The board can show notes or individual tasks grouped by their source note. It reports the state already in your files.

Choose where it lives.

Notes stay on your device by default. Full Unlock is a one-time purchase for Files-folder storage, GitHub, GitLab, OneDrive, and ZIP export. Local note-taking is free.

05 / About

Why I made it.

I built ioths for myself because the notes apps I had tried never quite fitted, either in what they did or how they felt to use.

The result is fairly specific: somewhere to write on the phone, keep the file, and add tasks without copying the thought into another tool. If you already use Obsidian, the file format will be familiar.
