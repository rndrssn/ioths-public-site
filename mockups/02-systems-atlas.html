01 / Design constraints

A useful tool begins
with useful limits.

C.01

Capture cannot depend
on a connection.

Write and read locally. A thought on a flight, underground, or away from a desk still has somewhere to go. Optional sync is a separate choice.

C.02

A thought should not need
a project definition.

Start with text. Checklist items turn a note into a task note when you have next steps. The question and its work stay together.

C.03

The file must remain useful
outside the application.

Notes are Markdown with YAML frontmatter. The format is compatible with Obsidian and readable in ordinary text editors.

C.04

Attention needs
an explicit boundary.

Set a limit on in-progress notes. Use the board to see what is open, active, and done, with checklist state determining the lanes.

02 / From text to action

The work is already
inside the note.

Give it a view.

A checklist describes the next steps. The Tasks view collects open items. Kanban shows notes or individual tasks grouped by their source note.

These are views of the same work. The original note keeps the surrounding thought intact.

03 / System boundaries

Know what the
tool takes on.

Where do the notes live?

On your device by default. You can choose an optional storage destination. One Library uses one storage mode at a time; ioths does not automatically connect every tool or vault.

How does it fit with Obsidian?

ioths uses Markdown files with YAML frontmatter, compatible with an Obsidian workflow. It provides a focused mobile capture surface. Connecting storage requires setup; format compatibility is not automatic two-way sync with any existing vault.

What does the purchase change?

Local note-taking is free. Full Unlock is a one-time purchase for optional capabilities, including Files-folder, GitHub, and GitLab storage. It is not a subscription.

Is this a model of how thinking works?

No. The app’s reference to emergence is an inspiration for its design. A note can gain structure through simple actions, but this is not a validated cognitive model or a claim of measured productivity gains.
